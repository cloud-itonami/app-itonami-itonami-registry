# 参照画像に忠実な図版を作る

製品図鑑、建築、植物、衣装、地図など、対象の形や配置が重要な画像向けの手順。AIの画像生成はもっともらしい細部を補うことがある。プロンプト、SVG、自己チェックはいずれも正確性を保証しない。生成物を証拠と見なさず、参照資料と人による確認を残す。

## 準備と判定基準

対象の名前・型番・版、用途、重要な不変条件、許容する省略、必要な解像度・形式を決める。正面に近く鮮明な写真、図面、公式マニュアルなどを用意し、出典・版・取得日と利用条件を記録する。対象や版の違う資料を混ぜず、食い違いは保留する。印刷・公開に使う資料やロゴなどの権利と利用条件は個別に確認する。

対象画像には構造の根拠、別画像には作風の根拠というように役割を明示する。見えない部分、判読できない文字、遠近や遮蔽による不確実性は「未確認」とし、想像で埋めない。ラベルは確認した文字を後で組版する選択肢もある。

## 1. 資料から仕様を作る

写真と資料を添付し、次のテンプレートの［ ］を埋める。

```text
［対象と版］について、添付資料から図版の仕様を作ってください。まだ描かないでください。
対象の輪郭と領域ごとに、要素の種類、個数、位置、並び、色、読める文字を一覧にし、
各項目に根拠の資料・ページまたは画像、確信度、未確認事項を付けてください。
資料間の相違と、隠れや遠近の影響も報告してください。
不明な点を推測で埋めず、確認が必要な質問を挙げてください。
```

AIの表も誤る。人が重要な個数、位置、文字と資料の対応を確認し、合意した版を基準仕様として保存する。参照写真が足りなければ追加するか、未確認箇所を図版に明記する。

## 2. 作画する

```text
添付の［構造の参照資料］と［確認済み仕様］を使い、［対象と版］の図版を作ってください。
用途は［用途］、構図は［構図］、作風は［作風］です。
［作風の参照画像］は表現だけに使い、対象の構造は構造の参照資料を優先してください。
［形状・個数・位置・並び・色・文字などの不変条件］を守り、要素を追加、削除、移動、
左右反転しないでください。確認できない部分を創作せず、未確認として報告してください。
見栄えより構造を優先し、保存した基準仕様との照合に必要な画像全体を出力してください。
```

複雑な実物感は画像生成を使い、正確な文字や規則的な部品はSVGなどの編集可能な図形で別に配置する方法もある。SVGは各要素のID・種類・座標・ラベルを編集・集計しやすく、拡大にも向くが、元の仕様や座標が誤っていれば図も誤る。写真の遠近とSVGの正投影を比較する場合は座標系を揃え、推定であることを記録する。

```text
確認済み仕様から編集可能なSVGを作ってください。各要素に一意のIDを付け、種類、領域、
座標、サイズ、ラベルを一覧にも出力してください。確認できない箇所は推測で描かず
未確認としてください。図形の集計を仕様と照合し、不一致を報告してください。
```

## 3. 独立して照合し、局所的に修正する

別のチャットやレビュー担当に、元資料・確認済み仕様・生成物を渡す。別のチャットでも誤りはあり、独立した証明にはならない。細部は人間が拡大して確認する。

```text
元資料、仕様、図版を領域ごとに比較してください。仕様自体の誤りも探してください。
形状、要素の種類と個数、位置関係、並び、色、文字、欠落・追加・反転を確認し、
「場所｜資料｜図版｜一致/不一致/未確認｜根拠｜修正案」の表にしてください。
判読できない場合は一致とせず未確認にしてください。出版可能と断定しないでください。
```

修正は一度に一箇所ずつ指定し、変更しない箇所も明示する。前の成果物と元資料を再添付し、修正後に全体と対象領域をもう一度比較する。画像編集でも指定外が変わり得るため、差分を確認する。

## 4. 回帰チェックを組み込む

基準仕様、参照の版、各生成物、プロンプト、モデル・設定、日時、修正履歴と判定を保存する。SVGならID、種類、数、座標、サイズ、文字を機械的に比較し、許可された変更以外を警告する。許容誤差と対象IDを先に決め、意図的に対象外の要素を変えた負の対照で警告が出ることを確かめる。画像のピクセル差分は色や微小なずれでも反応し、逆に意味のある誤りを見逃すことがあるため、領域別の目視と併用する。

```text
修正前後のSVGと基準仕様を比較する検査を作ってください。対象ID［ID］の［変更内容］だけを
許可し、他の要素の追加・削除・種類・座標・サイズ・文字の変更を報告してください。
比較不能は未確認として扱ってください。対象外の要素を意図的に変更した負の対照でも
警告を検証し、実行コマンドと結果を記録してください。
```

差分検査は元の誤りや実物との不一致を証明できない。最終的に資料と照合し、不一致と未確認を記録したうえで、必要に応じて対象に詳しい人が承認する。モデル名、設定、参照、出力を固定しても完全な再現は保証されない。
